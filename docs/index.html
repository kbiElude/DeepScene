DeepScene

A set of tools to capture the graphics API calls of a Windows program, study them, and use what was learned to turn a plain 3D demo into stereo 3D, live, on a monitor or in a VR headset.

The capture is done by API Interceptor, a library which this project has as a submodule. Everything else is here.

The jobs

Capture

Record every call of a program into a workload file, with the dumper of API Interceptor.

Replay

Play a workload back without the program, for both eyes, to try a recipe and to check that a frame can be drawn twice.

Analysis & recipes

Turn a workload into a .passes file, then bake a recipe that says how each draw is to be treated.

Live stereo

Inject a converter into the running program: it renders two eyes and passes the images on.

VR player

Launch programs, show the stereo image in a window, or in a headset through OpenXR.

How the parts fit

One API is not all of them

Direct3D 8 is the first API the tools support, and the demos are what drove the work, but the code is arranged for more. The parts that depend on an API are the ones listed in the table; everything else (the model of the analysis, the keys, the .passes file, the recipe format, the stereo decisions of StereoCore, the frame channel, the presenter and the VR player) does not know which API a program uses.

Adding an API means adding its row: its hooks, the front end that follows its state, its names for the printer, its replay executor and its converter adapter. The page Analysis & recipes lists what each piece is and where it goes.
